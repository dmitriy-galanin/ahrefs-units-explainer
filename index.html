1Что случилось

API units (юниты) — внутренняя «валюта» Ahrefs для доступа к данным через API (то есть когда данные забирает программа или AI-агент, а не человек в браузере). На нашем тарифе их 400 000 в месяц на весь аккаунт — общий котёл для всех. Это не деньги: юниты уже входят в оплаченную подписку, как гигабайты в мобильный тариф. Сгорели — счёт не придёт, просто до сброса счётчика остаётся меньший запас.

2Почему через API дорого, а руками — почти даром

Неочевидная вещь, из-за которой всё и случилось: внутри одной подписки Ahrefs — три раздельных счётчика, и они не пересекаются:

👀

Просмотр в браузере

На нашем тарифе — безлимит. Кликай и смотри отчёты сколько хочешь, ничего не списывается.

📥

Экспорт из браузера

Кнопка Export → CSV. Своя месячная квота «строк экспорта», тратится только в момент скачивания файла. На ядра её хватает с запасом.

🤖

API-юниты

Те самые 400 000 в месяц. Тратятся только когда данные забирает программа или агент. Человек из браузера потратить их не может физически.

Зачем так сложно: Ahrefs продаёт доступ к своей базе, и человеку они отдают данные щедро, а машинам — по жёсткому счётчику. Иначе любой скрипт выкачал бы всю базу за неделю.

Счётчик юнитов устроен просто: любой ответ API — это таблица, и юниты списываются за каждую её ячейку — каждый ключевик × каждая колонка данных о нём (частотность, сложность, цена клика…). Спросил 10 слов с парой колонок — потратил копейки. Попросил ядро — заказал самую большую таблицу из возможных:

Агент усиливает эффект: человек сделал бы одну выгрузку и остановился, а агент пробует снова и снова — синонимы, фильтры, пересортировки. Каждый заход платный, но агент «боли» от расхода не чувствует.

Ключевой факт: то же самое ядро руками из веб-интерфейса — почти даром. Там тратится отдельная экспортная квота, юниты не трогаются вообще.

Отсюда правило: массовые выгрузки — только из интерфейса (Keywords Explorer → сиды, то есть стартовые слова темы → Matching terms → Export), а агент — для точечных вопросов, где он реально быстрее, чем открывать Ahrefs руками.

3Что мы исправили

🛑

Лео больше не собирает ядра через API

В его правила зашито: полное ядро — только выгрузкой из веб-интерфейса, и он сам подскажет, что нажать (Keywords Explorer → сиды → Matching terms → Export). Через API — только точечное: интент, объёмы по списку слов, проверка выдачи.

💸

Жёсткая экономия в каждом запросе

Лео всегда просит маленькую таблицу: 50–100 ключевиков (максимум 250 — тысячу, которую Ahrefs отдаёт по умолчанию, не берёт никогда) и только нужные колонки. Не уверен в цене — сначала пробный запрос на 10 строк.

🧾

Цена вслух после каждого вызова

Каждый ответ Ahrefs содержит точную стоимость запроса. Лео теперь называет её: «этот запрос стоил 800 units». У команды появится интуиция, что дорого, а что копейки.

📓

Каждый запрос — в журнале

Журнал активности Лео теперь пишет и Ahrefs-запросы: какой инструмент, с какими ключевиками, кто попросил. Если юниты опять утекут — будет видно, куда именно.

🤝

Общая договорённость

Ядра и массовые выгрузки — руками из интерфейса Ahrefs. Агент — для быстрых вопросов из Slack, когда лень открывать Ahrefs ради одной цифры.

5Частые вопросы

Юниты — это деньги?
Нет. Они входят в уже оплаченную подписку, как гигабайты в мобильный тариф. Сгорели — счёт не придёт, докупать ничего не нужно.
Если Лео потратит все юниты, мы останемся без Ahrefs?
Нет. Замолчит только сам Лео (и любой другой программный доступ) — и только до сброса счётчика, у нас это 11 августа. Браузер, отчёты и экспорты продолжат работать как ни в чём не бывало.
Экспорт руками тратит юниты?
Нет. У экспорта из браузера своя отдельная месячная квота «строк экспорта», юниты она не трогает. А просмотр отчётов на нашем тарифе не тратит вообще ничего.
Сколько стоит обычный вопрос Лео?
Порядок такой: интент или топ выдачи по одному запросу — десятки юнитов, объёмы по списку из сотни слов — сотни юнитов. В месячный котёл 400 000 таких вопросов помещаются тысячи. Точную цену Лео сам называет после каждого ответа.
Кто ещё тратит юниты, кроме Лео?
Любая программа, подключённая к аккаунту по API. Котёл общий на весь аккаунт, так что счётчик на странице Лео на портале показывает суммарный расход — не только его собственный.
